# 🐍 Python Programming For Everyone – Learning Repository

This repository documents my progress through the **Python Programming For Everyone**
course from **Codemy.com**, taught by **John Elder**.

As one of my earliest Python learning experiences, this course introduced the
core concepts of programming and helped build the foundation for everything that
followed. The exercises and examples in this repository reflect my work while
learning Python fundamentals through hands-on practice.

Topics covered include variables, data types, strings, lists, tuples,
dictionaries, loops, functions, modules, and object-oriented programming.
